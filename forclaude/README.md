# Claude Keep Awake — project instructions

This folder contains the project specification and the context architecture for Claude Code.

## Start here

Read:
1. `CLAUDE.md`
2. `context/PROJECT.md`
3. `context/TECHNICAL.md`
4. `context/DECISIONS.md`
5. `context/SESSION.md`

Do not read every context file automatically. `CLAUDE.md` is intentionally small and acts as an index.

## Claude Code workflow

Work in explicit phases. At the end of every substantial phase:
- update `context/SESSION.md`;
- update `context/DECISIONS.md` only when a durable technical decision changes;
- update relevant context files when architecture/specification changes;
- keep `CLAUDE.md` short.

When starting a fresh Claude Code session, read `CLAUDE.md`, then only the context files relevant to the current phase. Do not reload the entire project context unless necessary.
